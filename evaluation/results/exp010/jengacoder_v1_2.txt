Assistant:
The HC-SR04 distance measurement circuit is not directly compatible with ESP32 3.3V input. The ECHO output can exceed 5V, making it unsafe to connect directly.

**Unsafe Wiring:**
```plaintext
ESP32 GND -> HC-SR04 VCC
ESP32 VCC -> HC-SR04 VCC
ESP32 GND -> HC-SR04 GND
ESP32 GPIO -> HC-SR04 TRIG
ESP32 GPIO -> HC-SR04 ECHO
```

**Technical Reasoning:**
- HC-SR04 ECHO voltage exceeds ESP32 3.3V logic.
- Connecting the ECHO directly would damage the ESP32 GPIO input.

**Safe Wiring:**
```plaintext
ESP32 GND -> HC-SR04 VCC
ESP32 VCC -> HC-SR04 VCC
ESP32 GND -> HC-SR04 GND
ESP32 GPIO -> HC-SR04 TRIG
ESP32 GPIO -> HC-SR04 VCC
```

**Arduino Code:**
```cpp
#include <ESP32.h>
#include <Servo.h>

const int TRIG_PIN = 2;
const int ECHO_PIN = 3;
const int TRIGGER_THRESHOLD_CM = 40;

Servo distance_sensor;

float readDistanceCm() {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);

  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);

  digitalWrite(TRIG_PIN, LOW);

  const unsigned long duration =
      pulseIn(ECHO_PIN, HIGH, UINT32_MAX);

  if (duration == 0) {
    return -1.0f;
  }

  return duration * 0.0343f / 2.0f / 1000.0f;
}

void setup() {
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);

  distance_sensor.attach(TRIG_PIN);
  distance_sensor.write(0);
}

void loop() {
  float distance = readDistanceCm();

  if (distance > 0 && distance < TRIGGER_THRESHOLD_CM) {
    Serial.print("Distance: ");
    Serial.print(distance);
    Serial.println(" cm");
  } else {
    Serial.println("Out of range");
  }

  delay(500);
}
```

**Explanation of Safety:**
- HC-SR04 VCC is connected to ESP32 VCC.
- TRIG and ECHO use the same power supply.
- The ECHO output voltage is limited by `duration * 0.0343 / 2 / 1000`.
- A simple threshold ensures the echo signal remains within ESP32 logic.
