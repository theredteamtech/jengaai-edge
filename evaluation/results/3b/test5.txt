Mmoja mdogo wa Python unaotumia variable, if statement, loop na function pamoja:

```python
# Variable
name = "John"

# If statement
if name == "John":
    print("Hello, John!")

# Loop
for i in range(5):
    print(i)

# Function
def greet(name):
    return "Hello, " + name + "!"

print(greet("John"))
```
