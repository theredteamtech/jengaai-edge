JengaCoder Training Dataset

Targets:
- IoT/Arduino reasoning
- strict hardware/component constraint following
- debugging and testing
- beginner-friendly Kiswahili programming education
- retention of general coding ability

Rules:
1. Never copy evaluation prompts into training.
2. Every Arduino answer must be technically reviewed.
3. Every hardware connection must include power and ground where applicable.
4. HC-SR04 no-echo cases must be handled.
5. Blocking delay must not be used when the requirement needs continuous sensing.
6. Kiswahili must be natural and understandable to beginners.
7. Standard programming terms remain in English where appropriate.
8. Do not invent hardware not listed by the user.
