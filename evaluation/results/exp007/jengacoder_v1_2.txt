User:
You have exactly these components:

- Arduino Uno
- One 10k ohm potentiometer
- One LED
- One 220 ohm resistor
- Jumper wires

Build a circuit where turning the potentiometer smoothly changes the brightness of the LED.

Requirements:
1. Connect one outer potentiometer pin to Arduino 5V.
2. Connect the other outer potentiometer pin to Arduino GND.
3. Connect the potentiometer wiper to analog pin A0.
4. Connect the LED to PWM-capable digital pin 9 through the 220 ohm resistor.
5. Read the potentiometer using analogRead(A0).
6. Convert the 0-1023 analog reading to a 0-255 PWM value.
7. Control LED brightness using analogWrite(9, value).
8. Do not use INPUT_PULLUP.
9. Do not change the specified pins.
10. Do not add, use, or mention any component that is not listed above.
11. Give pin-by-pin wiring.
12. Give a complete Arduino sketch.
13. Give a short test procedure.

Give only the wiring, code, and test procedure.

Assistant:
### Wiring
- Arduino Uno → Potentiometer
  - VCC → 5V
  - GND → GND
  - Wiper → A0

- Arduino Uno → LED
  - Red/VCC → 5V
  - Ground → GND
  - Data/LED → pin 9 (PWM)

### Arduino Sketch

```cpp
const int LED_PIN = 9;
const int POTENTIOMETER_PIN = A0;

void setup() {
  pinMode(LED_PIN, OUTPUT);
  analogWriteRange(255); // LED control from 0 to 255
}

void loop() {
  int potValue = analogRead(POTENTIOMETER_PIN);
  float brightness = map(potValue, 0, 1023, 0, 255);
  analogWrite(LED_PIN, brightness);

  delay(10); // Debounce
}
```

### Test Procedure
1. Upload the sketch to the Arduino Uno.
2. Turn the potentiometer clockwise to see the LED dimmer.
3. Turn the potentiometer counterclockwise to see the LED brighter.
4. Observe that no other components are involved.
