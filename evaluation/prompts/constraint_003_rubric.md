# Constraint 003 Rubric — C++ Resource Constraints

Maximum score: 10

1. Correct result logic — 2 points
   - Finds the largest value correctly.
   - Counts how many times the largest value occurs correctly.

2. Single traversal — 2 points
   - Processes the array in one pass only.

3. O(1) additional memory — 2 points
   - Uses only a fixed number of scalar variables.
   - Does not create another array or copy the input.

4. No forbidden memory behavior — 1 point
   - No recursion.
   - No dynamic allocation.
   - No vector, map, set, unordered_map, or other dynamically allocating container.

5. Correct C++17 program — 1 point
   - Complete and compilable.

6. 100-element sample array — 1 point
   - Initializes exactly 100 signed 16-bit integers directly in the program.

7. Explanation and constraint justification — 1 point
   - Briefly explains why all constraints are satisfied.

This prompt is frozen evaluation material and must not be used for training.
